## Условия проверки

Локальный сквозной прогон использовал Nginx, собранный Java API с H2 в режиме
PostgreSQL, Python, Go и Mailpit. Для изоляции использованы порты 18880 и 18025.
Docker daemon в этой среде отсутствует, поэтому строка SKIP в api-local.txt
относится именно к пересозданию контейнеров, а не к проверкам API или SMTP.

Полный Compose с PostgreSQL 16 и проверкой томов запускается в Ubuntu командой
`sudo bash scripts/check.sh --check-persistence`. Этот новый прогон нужно
выполнить после применения обновления; он сохраняет реальные результаты
в docs/evidence/runtime/.

Скриншоты фактического запуска с PostgreSQL в Ubuntu приведены
в [README доказательств](README.md).
