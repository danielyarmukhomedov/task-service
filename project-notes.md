# Заметки по проекту

Реализована система управления задачами с приоритетами и статусом выполнения.
Java API хранит задачи в PostgreSQL, Python отправляет SMTP-уведомления в Mailpit,
Go считает события создания задач. SPA обращается к сервисам через Nginx.

Планы развития: пользователи, проекты, теги, авторизация, Redis-кеширование и
долговечная очередь уведомлений. Эти функции пока не реализованы.
